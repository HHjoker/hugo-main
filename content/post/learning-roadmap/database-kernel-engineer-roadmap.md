## 📌 路线背景

基于 **OceanBase 日志系统/高可用架构研发岗位** 要求制定，目标是从通信领域 C++ 开发转型到数据库内核研发。

### 目标岗位核心要求

```
1. 熟练掌握 C/C++ 语言，熟悉数据结构、算法、操作系统
2. 熟悉关系数据库和/或分布式系统的运行机制和架构体系
3. 加分项：一致性协议、分布式事务、存储引擎经验
4. 加分项：底层系统研发经验或关系数据库研发经验
5. 加分项：熟悉 Rust 语言，或有意愿使用 Rust 开发分布式系统
```

### 个人背景分析

| 维度 | 当前状态 | 目标状态 | 差距 |
|------|---------|---------|------|
| **C++ 能力** | 2 年半基站数据解析经验 | 数据库内核级 C++ | ⚠️ 中等 |
| **数据库知识** | 应用层使用 | 内核研发 | ⚠️ 较大 |
| **分布式系统** | 有限接触 | Paxos、一致性协议 | ⚠️ 较大 |
| **Rust 语言** | 0 基础 | 能用于系统开发 | ⚠️ 从零开始 |
| **存储引擎** | 未涉及 | WAL、日志系统 | ⚠️ 较大 |

**预计学习周期**：6-12 个月（在职学习）

## 📚 第一阶段：C++ 深度提升（第 1-2 月）

### 目标
达到数据库内核研发要求的 C++ 水平，超越应用层开发。

### 学习内容

#### 1.1 C++ 高级特性

| 主题 | 具体内容 | 资源推荐 | 耗时 |
|------|---------|---------|------|
| **内存管理** | 智能指针、自定义分配器、内存池 | 《Effective C++》第 1-3 章 | 1 周 |
| **模板编程** | 模板元编程、SFINAE、constexpr | 《C++ Templates》前 8 章 | 2 周 |
| **移动语义** | 右值引用、完美转发、移动优化 | 《Effective Modern C++》 | 1 周 |
| **并发编程** | 线程、锁、原子操作、无锁数据结构 | 《C++ Concurrency in Action》 | 2 周 |

#### 1.2 数据结构与算法强化

| 主题 | 具体内容 | 练习平台 | 目标 |
|------|---------|---------|------|
| **高级数据结构** | B/B+ 树、跳表、哈希表、布隆过滤器 | LeetCode | 50 题 |
| **字符串算法** | KMP、Trie、后缀数组 | LeetCode | 20 题 |
| **图算法** | 最短路径、拓扑排序、并查集 | LeetCode | 30 题 |

#### 1.3 操作系统深入

| 主题 | 具体内容 | 资源推荐 |
|------|---------|---------|
| **进程/线程** | 调度、上下文切换、线程池 | 《操作系统导论》 |
| **内存管理** | 虚拟内存、页表、TLB | 《深入理解计算机系统》 |
| **I/O 系统** | 缓冲、异步 I/O、mmap | 《Linux/UNIX 系统编程手册》 |
| **文件系统** | 日志文件系统、写时复制 | 阅读 ext4 文档 |

### 推荐书籍

必读：
- 《Effective C++》（第 3 版）- Scott Meyers

- 《深入理解计算机系统》（CSAPP）- 第 3 版

## 🗄️ 第二阶段：数据库内核原理（第 3-4 月）

### 目标
理解数据库内核核心模块，掌握存储引擎工作原理。

### 学习内容

#### 2.1 数据库架构概览

```
┌─────────────────────────────────────────────────────┐
│                    SQL Layer                        │
│  (Parser, Optimizer, Executor, Planner)            │
├─────────────────────────────────────────────────────┤
│                 Transaction Layer                   │
│  (Concurrency Control, Lock Manager, MVCC)         │
├─────────────────────────────────────────────────────┤
│                  Storage Engine                     │
│  (WAL, Buffer Pool, B+ Tree, Page Manager)         │
├─────────────────────────────────────────────────────┤
│                    OS / Disk                        │
└─────────────────────────────────────────────────────┘
```

#### 2.2 核心模块详解

| 模块 | 学习内容 | 资源推荐 | 耗时 |
|------|---------|---------|------|
| **SQL 解析** | 词法分析、语法分析、AST | 《数据库系统概念》Ch3 | 1 周 |
| **查询优化** | 规则优化、代价优化、执行计划 | 《数据库系统实现》Ch15-16 | 2 周 |
| **事务管理** | ACID、隔离级别、锁、MVCC | 《数据库系统概念》Ch17 | 2 周 |
| **存储引擎** | 页管理、缓冲池、B+ 树索引 | 《数据库系统实现》Ch7-8 | 2 周 |
| **WAL 日志** | Write-Ahead Logging、预写式日志 | CMU 15-445 | 1 周 |
| **恢复系统** | Checkpoint、ARIES 算法 | 《数据库系统实现》Ch18 | 1 周 |

#### 2.3 推荐课程

| 课程 | 平台 | 难度 | 链接 |
|------|------|------|------|
| **CMU 15-445** | YouTube/B 站 | ⭐⭐⭐⭐ | [链接](https://www.youtube.com/results?search_query=cmu+15-445) |
| **CS346** | Stanford | ⭐⭐⭐⭐⭐ | [链接](https://web.stanford.edu/class/cs346/2015/) |
| **MIT 6.830** | MIT OCW | ⭐⭐⭐⭐ | [链接](https://ocw.mit.edu/courses/6-830-database-systems-fall-2010/) |

### 推荐书籍

```
必读：
- 《数据库系统概念》（第 7 版）- Abraham Silberschatz
- 《数据库系统实现》- Hector Garcia-Molina

选读：
- 《Readings in Database Systems》（Red Book）- 论文合集
- 《Designing Data-Intensive Applications》- Martin Kleppmann
```

### 实践项目

1. **实现一个简单的存储引擎**
   - 支持页管理（Page Manager）
   - 实现 B+ 树索引
   - 支持简单的 CRUD 操作

2. **实现 WAL 日志系统**
   - 预写式日志
   - 支持崩溃恢复
   - Checkpoint 机制

## 🌐 第三阶段：分布式系统（第 5-6 月）

### 目标
掌握分布式系统核心原理，理解一致性协议。

### 学习内容

#### 3.1 分布式系统基础

| 主题 | 具体内容 | 资源推荐 |
|------|---------|---------|
| **分布式基础** | CAP 定理、BASE 理论、一致性模型 | 《分布式系统原理与范型》 |
| **时间与时钟** | 逻辑时钟、向量时钟、混合逻辑时钟 | 论文阅读 |
| **分布式共识** | 两阶段提交、三阶段提交 | 《DDIA》Ch9 |
| **复制技术** | 主从复制、多主复制、无主复制 | 《DDIA》Ch5 |

#### 3.2 一致性协议（重点）

| 协议 | 学习内容 | 难度 | 资源 |
|------|---------|------|------|
| **Paxos** | Basic Paxos、Multi-Paxos | ⭐⭐⭐⭐⭐ | [Paxos 论文](https://lamport.azurewebsites.net/pubs/pubs.html#lamport-paxos) |
| **Raft** | Leader 选举、日志复制、安全性 | ⭐⭐⭐⭐ | [Raft 官网](https://raft.github.io/) |
| **ZAB** | ZooKeeper 原子广播协议 | ⭐⭐⭐⭐ | ZooKeeper 源码 |
| **Gossip** | 病毒式传播、最终一致性 | ⭐⭐⭐ | Dynamo 论文 |

#### 3.3 分布式事务

| 主题 | 具体内容 | 资源 |
|------|---------|------|
| **2PC/3PC** | 两阶段/三阶段提交协议 | 《DDIA》Ch9 |
| **TCC** | Try-Confirm-Cancel 模式 | 阿里文档 |
| **Saga** | 长事务编排 | 论文阅读 |
| **Percolator** | Google 分布式事务模型 | 论文阅读 |

### 推荐书籍

```
必读：
- 《Designing Data-Intensive Applications》（DDIA）- Martin Kleppmann
- 《分布式系统原理与范型》- Andrew S. Tanenbaum

选读：
- 《大规模分布式存储系统》- 杨传辉
- 《数据密集型应用系统设计》实战解读
```

### 实践项目

1. **实现 Raft 协议**
   - Leader 选举
   - 日志复制
   - 成员变更
   - 参考：[MIT 6.824 Lab2](https://pdos.csail.mit.edu/6.824/labs/lab-raft.html)

2. **实现一个简单的分布式 KV 存储**
   - 基于 Raft 保证一致性
   - 支持多节点部署
   - 实现基本的 PUT/GET 操作
