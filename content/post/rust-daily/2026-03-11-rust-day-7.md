## 📚 今日学习内容

### 1. 什么是所有权（Ownership）？

所有权是 Rust 最核心的特性，它是一套**内存管理规则**，在编译期检查内存安全，无需垃圾回收器。

#### 为什么需要所有权？

在其他语言中：

```javascript
// JavaScript - 垃圾回收自动管理
let s1 = "hello";
let s2 = s1;  // s1 和 s2 都可以用
console.log(s1);  // ✅ "hello"
console.log(s2);  // ✅ "hello"
```

```cpp
// C++ - 需要手动管理，容易出错
char* s1 = malloc(6);
strcpy(s1, "hello");
char* s2 = s1;  // 浅拷贝，两个指针指向同一内存
free(s1);
// free(s2);  // ❌ 双重释放！
// 或者忘记 free → 内存泄漏
```

```rust
// Rust - 编译期保证安全
let s1 = String::from("hello");
let s2 = s1;  // s1 的所有权转移到 s2
// println!("{}", s1);  // ❌ 编译错误！s1 已无效
println!("{}", s2);  // ✅ "hello"
```

### 2. 所有权三规则

Rust 的所有权系统基于三条简单规则：

#### 规则 1：每个值都有一个所有者

```rust
fn main() {
    let x = 5;        // x 是 5 的所有者
    let s = String::from("hello");  // s 是字符串的所有者
    let v = vec![1, 2, 3];  // v 是向量的所有者
}  // 这里所有变量都离开作用域，内存被释放
```

#### 规则 2：同一时间只能有一个所有者

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;  // s1 的所有权转移给 s2
    
    // println!("{}", s1);  // ❌ 编译错误！
    // error[E0382]: borrow of moved value: `s1`
    
    println!("{}", s2);  // ✅ "hello"
}
```

#### 规则 3：当所有者离开作用域，值被丢弃

```rust
fn main() {
    {
        let s = String::from("hello");
        println!("{}", s);  // ✅ 可以使用
    }  // s 离开作用域，内存自动释放（调用 drop）
    
    // println!("{}", s);  // ❌ 编译错误！s 已不存在
}
```

### 3. 栈上数据 vs 堆上数据

理解所有权，首先要理解 Rust 如何存储数据。

#### 栈（Stack）

- **固定大小**：编译时知道大小
- **快速访问**：LIFO（后进先出）
- **自动管理**：离开作用域自动弹出

```rust
fn main() {
    // 这些类型大小固定，存储在栈上
    let x: i32 = 5;
    let y: f64 = 3.14;
    let z: bool = true;
    let t: char = 'a';
    
    // 固定大小的数组也在栈上
    let arr: [i32; 5] = [1, 2, 3, 4, 5];
}
```

#### 堆（Heap）

- **动态大小**：运行时才能确定大小
- **灵活**：可以增长或缩小
- **需要管理**：需要跟踪谁负责释放

```rust
fn main() {
    // String 大小可变，数据存储在堆上
    let s = String::from("hello");
    
    // Vec 大小可变，数据存储在堆上
    let v = vec![1, 2, 3];
    
    // Box 用于在堆上分配数据
    let b = Box::new(42);
}
```

#### 内存布局示意

```
栈（Stack）                    堆（Heap）
+----------------+            +----------------+
| s (指针)       | ---------> | "hello" (数据) |
|    0x1000      |            |    长度：5     |
+----------------+            |    容量：5     |
| len: 5         |            +----------------+
| capacity: 5    |
+----------------+
```

### 4. Move 语义（所有权转移）

这是 Rust 与大多数语言最大的不同。

#### 基础 Move

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;  // Move：s1 的所有权转移给 s2
    
    // s1 现在无效了！
    // println!("{}", s1);  // ❌ 编译错误
    println!("{}", s2);  // ✅ "hello"
}
```

#### Move 在函数中

```rust
// 函数获取所有权
fn take_ownership(s: String) {
    println!("函数内：{}", s);
}  // s 离开作用域，内存释放

fn main() {
    let s = String::from("hello");
    take_ownership(s);  // s 的所有权转移给函数
    
    // println!("{}", s);  // ❌ 编译错误！s 已无效
}
```

#### 返回所有权

```rust
// 函数返回所有权
fn give_ownership() -> String {
    let s = String::from("hello");
    s  // 返回 s，所有权转移给调用者
}

fn main() {
    let s = give_ownership();  // s 获得所有权
    println!("{}", s);  // ✅ "hello"
}  // s 离开作用域，内存释放
```

#### 函数参数和返回值

```rust
// 获取所有权并返回
fn take_and_give_back(s: String) -> String {
    println!("处理：{}", s);
    s  // 返回所有权
}

fn main() {
    let s1 = String::from("hello");
    let s2 = take_and_give_back(s1);  // s1 → 函数 → s2
    
    // println!("{}", s1);  // ❌ s1 已无效
    println!("{}", s2);  // ✅ "hello"
}
```

### 5. Clone 和 Copy

#### Clone：深拷贝

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1.clone();  // 深拷贝：复制堆上数据
    
    println!("s1 = {}, s2 = {}", s1, s2);  // ✅ 两者都可以用
    // s1 = hello, s2 = hello
}
```

#### Copy trait

某些类型实现了 `Copy` trait，赋值时自动复制而不是 Move：

```rust
fn main() {
    // 这些类型实现了 Copy
    let x = 5;
    let y = x;  // 复制，不是 Move
    println!("x = {}, y = {}", x, y);  // ✅ 两者都可以用
    
    let a = 3.14;
    let b = a;
    println!("a = {}, b = {}", a, b);  // ✅
    
    let c = true;
    let d = c;
    println!("c = {}, d = {}", c, d);  // ✅
}
```

#### 哪些类型实现了 Copy？

```rust
// 所有整数类型
let a: i8 = 1;
let b: u32 = 2;
let c: i128 = 3;

// 浮点类型
let d: f32 = 1.5;
let e: f64 = 2.5;

// 布尔类型
let f: bool = true;

// 字符类型
let g: char = 'a';

// 元组（仅当所有元素都实现 Copy）
let h: (i32, f64, bool) = (1, 2.0, true);

// 数组（仅当元素实现 Copy 且大小固定）
let i: [i32; 5] = [1, 2, 3, 4, 5];
```

#### String 为什么不实现 Copy？

```rust
// String 不实现 Copy，因为：
// 1. 它管理堆上数据
// 2. 自动复制会导致双重释放问题
// 3. 需要显式 clone() 表明意图

fn main() {
    let s1 = String::from("hello");
    // let s2 = s1;  // Move，不是 Copy
    let s2 = s1.clone();  // 必须显式克隆
}
```

### 6. Drop trait

当值离开作用域时，Rust 自动调用 `drop` 函数清理资源。

#### 自动 Drop

```rust
fn main() {
    let s = String::from("hello");
    println!("{}", s);
}  // 这里自动调用 drop(s)，释放堆内存
```

#### 手动 Drop（不推荐）

```rust
fn main() {
    let s = String::from("hello");
    drop(s);  // 手动调用 drop
    
    // println!("{}", s);  // ❌ 编译错误！s 已被丢弃
}
```

#### 自定义 Drop

```rust
struct MyResource {
    name: String,
}

impl Drop for MyResource {
    fn drop(&mut self) {
        println!("正在释放资源：{}", self.name);
        // 这里可以执行清理操作
    }
}

fn main() {
    let r1 = MyResource { name: String::from("资源 1") };
    let r2 = MyResource { name: String::from("资源 2") };
    
    println!("程序结束前");
    // 输出：程序结束前
    
}  // 自动调用 drop：
   // 正在释放资源：资源 2（后进先出）
   // 正在释放资源：资源 1
```

#### Drop 顺序

```rust
fn main() {
    let a = MyResource { name: String::from("a") };
    let b = MyResource { name: String::from("b") };
    let c = MyResource { name: String::from("c") };
    
    drop(b);  // 手动 drop b
    
}  // 自动 drop 顺序：c, a（b 已经被手动 drop 了）
```

### 7. 所有权与函数

#### 完整示例

```rust
// 创建字符串
fn create_string() -> String {
    String::from("hello")
}

// 获取所有权
fn take_string(s: String) {
    println!("收到：{}", s);
}  // s 被 drop

// 借用（不获取所有权）- 明天学习
fn borrow_string(s: &String) {
    println!("借用：{}", s);
}

// 返回部分所有权
fn return_part(s: String) -> (String, String) {
    let prefix = s[..2].to_string();
    (s, prefix)
}

fn main() {
    // 创建
    let s1 = create_string();
    
    // 转移所有权
    take_string(s1);
    // println!("{}", s1);  // ❌ s1 已无效
    
    // 重新创建
    let s2 = String::from("world");
    
    // 返回多个值
    let (s3, prefix) = return_part(s2);
    println!("原字符串：{}, 前缀：{}", s3, prefix);
}
```

## 🔑 关键概念理解

### 1. Move 是 Rust 的核心

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;  // Move 发生
    
    // 为什么 Rust 要这样设计？
    // 答案：防止双重释放（double free）
}
```

如果 Rust 允许 `s1` 和 `s2` 都指向同一块堆内存：

```
危险情况：
s1 和 s2 都指向同一块内存
当 s1 离开作用域 → 释放内存
当 s2 离开作用域 → 再次释放同一内存 → ❌ 双重释放！
```

Rust 通过 Move 语义，确保**只有一个变量负责释放内存**。

### 2. 浅拷贝 vs 深拷贝

```rust
// 浅拷贝（Move）
let s1 = String::from("hello");
let s2 = s1;  // 只复制指针、长度、容量，不复制数据

// 深拷贝（Clone）
let s3 = String::from("world");
let s4 = s3.clone();  // 复制所有数据到新的堆内存
```

### 3. 栈复制 vs 堆移动

```rust
// 栈上数据 - 自动复制（Copy）
let x = 5;
let y = x;  // 简单的位复制，非常快

// 堆上数据 - 需要 Move 或 Clone
let s1 = String::from("hello");
let s2 = s1;  // Move：s1 无效
let s3 = s1.clone();  // Clone：深拷贝，较慢
```
