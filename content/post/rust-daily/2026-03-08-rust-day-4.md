## 📚 今日学习内容

### 1. 所有权的三条规则

Rust 的所有权系统遵循三条简单但强大的规则：

1. **每个值都有一个所有者（owner）**
2. **同一时刻只能有一个所有者**
3. **当所有者离开作用域，值会被丢弃（drop）**

```rust
fn main() {
    // x 是 5 的所有者
    let x = 5;
    
    // y 成为 "hello" 的所有者
    let y = String::from("hello");
    
    // 当 main 函数结束，x 和 y 都会被 drop
}  // ← 这里 x 和 y 离开作用域，内存被释放
```

**为什么需要所有权？**

在其他语言中，内存管理是个难题：
- C/C++：手动管理，容易内存泄漏和野指针
- Java/Python：垃圾回收，有运行时开销

Rust 通过所有权系统，在**编译期**就解决内存问题，**零运行时开销**！

### 2. 栈（Stack）与堆（Heap）

理解所有权前，先了解内存布局：

```rust
fn main() {
    // 栈上：大小固定，编译期已知
    let x = 5;              // i32，4 字节
    let y = true;           // bool，1 字节
    let z = (1, 2.0);       // 元组，大小固定
    
    // 堆上：大小可变，运行时确定
    let s = String::from("hello");  // 字符串长度可变
    let v = vec![1, 2, 3];          // Vec 大小可变
}
```

**栈 vs 堆**：

| 特性 | 栈（Stack） | 堆（Heap） |
|------|-----------|-----------|
| 速度 | 快（LIFO） | 慢（需要分配） |
| 大小 | 固定 | 可变 |
| 访问 | 直接 | 通过指针 |
| 例子 | i32, bool, char | String, Vec, Box |

**String 的内存布局**：

```rust
let s = String::from("hello");
```

```
栈内存                堆内存
┌─────────┐          ┌─────────┐
│  ptr    │─────────▶│  h e l  │
│  (地址) │          │  l o    │
│  len=5  │          │  (数据) │
│ cap=5   │          └─────────┘
└─────────┘
```

String 在栈上存储：指针、长度、容量  
实际数据在堆上

### 3. 所有权与变量

#### 3.1 移动语义（Move Semantics）

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;  // ⚠️ 注意：这不是拷贝！
    
    // println!("{}", s1);  // ❌ 编译错误！s1 已无效
    println!("{}", s2);  // ✅ 可以，s2 是所有者
}
```

**发生了什么？**

```
赋值前：
s1 ──▶ [堆上的 "hello"]

赋值 s2 = s1 后：
s1 ──▶ [堆上的 "hello"] ◀── s2
       (但 s1 无效了！)

Rust 的做法：
- 复制栈上的数据（ptr, len, cap）
- s1 被标记为无效
- 只有 s2 是所有者
```

**为什么这样设计？**

如果 s1 和 s2 都是所有者：
- 两者都会尝试释放同一块内存 → **双重释放（double free）**
- 这是严重的安全漏洞！

Rust 通过移动语义，在编译期就防止这个问题。

#### 3.2 Copy trait

某些类型实现了 `Copy` trait，赋值时会真正拷贝：

```rust
fn main() {
    let x = 5;
    let y = x;  // ✅ i32 实现了 Copy，真正拷贝
    
    println!("x = {}, y = {}", x, y);  // 都可以用
    
    // 实现了 Copy 的类型：
    // - 所有整数类型：u8, i32, u64...
    // - bool
    // - char
    // - 浮点数：f32, f64
    // - 元组（如果内部类型都实现 Copy）
    // - 数组（如果元素实现 Copy）
}
```

**Copy vs Move**：

```rust
fn main() {
    // Copy 类型：赋值后原变量仍可用
    let x = 42;
    let y = x;
    println!("{}", x);  // ✅
    
    // Move 类型：赋值后原变量无效
    let s1 = String::from("hi");
    let s2 = s1;
    // println!("{}", s1);  // ❌ 编译错误
}
```

### 4. 所有权与函数

#### 4.1 参数获取所有权

```rust
fn main() {
    let s = String::from("hello");
    takes_ownership(s);
    
    // println!("{}", s);  // ❌ s 已无效
}

fn takes_ownership(some_string: String) {
    println!("{}", some_string);
}  // some_string 离开作用域，被 drop
```

#### 4.2 借用（Borrowing）- 引用

不想转移所有权？使用引用：

```rust
fn main() {
    let s = String::from("hello");
    
    // 传递引用，不转移所有权
    let len = calculate_length(&s);
    
    println!("The length of '{}' is {}.", s, len);  // ✅ s 仍可用
}

fn calculate_length(s: &String) -> usize {
    s.len()
}  // s 离开作用域，但不会 drop 数据（只是引用）
```

**引用的符号**：
- `&T`：不可变引用（借用）
- `&mut T`：可变引用（可变借用）

#### 4.3 可变引用

```rust
fn main() {
    let mut s = String::from("hello");
    
    change(&mut s);
    
    println!("{}", s);  // 输出："hello, world"
}

fn change(some_string: &mut String) {
    some_string.push_str(", world");
}
```

**借用规则**：
1. 同一时刻，要么有一个可变引用，要么有任意数量的不可变引用
2. 引用必须始终有效（不能悬垂引用）

```rust
fn main() {
    let mut s = String::from("hello");
    
    let r1 = &s;      // ✅ 不可变引用
    let r2 = &s;      // ✅ 可以有多个不可变引用
    // let r3 = &mut s;  // ❌ 错误！已有不可变引用时不能有可变引用
    
    println!("{}, {}, and {}", r1, r2, s);
    // r1 和 r2 作用域结束
    
    let r3 = &mut s;  // ✅ 现在可以了
    r3.push_str(", world");
}
```

### 5. 克隆（Clone）- 深拷贝

如果需要真正复制堆数据，使用 `clone()`：

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1.clone();  // 深拷贝，堆数据也复制
    
    println!("s1 = {}, s2 = {}", s1, s2);  // ✅ 两者都可用
}
```

**clone() 的内存效果**：

```
s1.clone() 后：
s1 ──▶ [堆上的 "hello"] (第一份)
s2 ──▶ [堆上的 "hello"] (第二份，独立副本)
```

**何时使用 clone？**
- 确实需要两份独立的数据
- 性能不是关键（clone 有开销）
- 需要保留原值的所有权

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;  // 移动，s1 无效
    
    let s3 = String::from("world");
    let s4 = s3.clone();  // 克隆，s3 和 s4 都有效
    
    use_both(s3, s4);
}

fn use_both(s1: String, s2: String) {
    println!("{} {}", s1, s2);
}
```

### 6. 作用域与 Drop

#### 6.1 作用域规则

```rust
fn main() {
    {
        let s = String::from("hello");
        println!("{}", s);
    }  // ← s 离开作用域，内存被释放
    
    // println!("{}", s);  // ❌ s 已不存在
}
```

#### 6.2 Drop trait

当值离开作用域，Rust 自动调用 `drop()`：

```rust
struct MyResource {
    name: String,
}

impl Drop for MyResource {
    fn drop(&mut self) {
        println!("Dropping {}", self.name);
    }
}

fn main() {
    let a = MyResource { name: String::from("A") };
    let b = MyResource { name: String::from("B") };
    
    println!("Before end of scope");
    
    {
        let c = MyResource { name: String::from("C") };
        println!("Inside inner scope");
    }  // c 被 drop
    
    println!("After inner scope");
}  // b 被 drop，然后 a 被 drop

// 输出：
// Before end of scope
// Inside inner scope
// Dropping C
// After inner scope
// Dropping B
// Dropping A
```

**后进先出（LIFO）**：最后创建的变量最先被 drop

#### 6.3 提前 drop

```rust
fn main() {
    let mut s = String::from("hello");
    
    {
        let s2 = &mut s;
        s2.push_str(", world");
    }  // s2 的借用结束
    
    // 现在可以再次借用 s
    println!("{}", s);
    
    // 手动提前 drop（很少需要）
    drop(s);
    
    // println!("{}", s);  // ❌ s 已被 drop
}
```

## 💡 关键概念理解

### 1. 所有权转移的时机

```rust
fn main() {
    // 赋值时转移
    let s1 = String::from("hi");
    let s2 = s1;  // s1 → s2
    
    // 函数传参时转移
    fn take(s: String) {}
    take(s2);  // s2 → 函数参数
    
    // 函数返回时转移
    fn give() -> String {
        String::from("hello")
    }
    let s3 = give();  // 返回值 → s3
}
```

### 2. 引用的生命周期

```rust
fn main() {
    let r;
    {
        let x = 5;
        r = &x;  // ❌ 编译错误！x 的生命周期比 r 短
    }
    // println!("{}", r);  // r 引用了已释放的内存
}
```

Rust 的借用检查器会确保引用不会比被引用的值活得更久。

### 3. &String vs &str

```rust
fn main() {
    let s = String::from("hello");
    
    // &String：引用 String 对象
    fn takes_string_ref(s: &String) {}
    takes_string_ref(&s);
    
    // &str：字符串切片（更常用）
    fn takes_str_slice(s: &str) {}
    takes_str_slice(&s);      // &String 可以转为 &str
    takes_str_slice("hello"); // 字符串字面量是 &str
    
    // 推荐：函数参数用 &str，更灵活
}
```

### 4. 所有权规则总结

```rust
fn main() {
    // 规则 1：每个值有一个所有者
    let s = String::from("hello");  // s 是所有者
    
    // 规则 2：同一时刻只有一个所有者
    let s2 = s;  // 所有权转移给 s2，s 无效
    
    // 规则 3：所有者离开作用域，值被 drop
}  // s2 离开作用域，String 被 drop
```

## 💭 今日感悟

> 所有权是 Rust 的精髓。一开始会觉得束缚，但理解了之后会发现它带来的安全感。

> 移动语义的设计非常巧妙：**编译期防止双重释放**，不需要垃圾回收器。

> 借用规则（要么一个可变引用，要么多个不可变引用）一开始难记，但想想就合理：
> - 多人同时读没问题
> - 但有人写的时候，别人不能读也不能写

> `&str` 比 `&String` 更灵活，因为可以接受字符串字面量和 String 的引用。以后函数参数优先用 `&str`。

> clone() 是显式的，这很好。在 Rust 中，昂贵的操作（如堆内存复制）必须显式调用，不会偷偷发生。

> Drop trait 让资源清理变得优雅。不仅是内存，文件、网络连接等都可以用 Drop 自动清理。
