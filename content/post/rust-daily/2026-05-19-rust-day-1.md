## 📚 学习内容

### 什么是变量？

在 Rust 中，变量使用 `let` 关键字声明：

```rust
fn main() {
    let x = 5;
    println!("x 的值是：{}", x);
}
```

运行结果：
```
x 的值是：5
```

### 可变变量

默认情况下，Rust 的变量是**不可变的**（immutable）。这意味着一旦赋值，就不能改变它的值。这是一种安全特性，能帮助我们避免很多 bug。

但如果你需要修改变量的值，可以使用 `mut` 关键字：

```rust
fn main() {
    let mut x = 5;
    println!("修改前 x 的值是：{}", x);
    
    x = 6;  // 现在可以修改了
    println!("修改后 x 的值是：{}", x);
}
```

运行结果：
```
修改前 x 的值是：5
修改后 x 的值是：6
```

### 变量遮蔽（Shadowing）

Rust 允许我们声明一个与已存在变量同名的变量，这叫做"变量遮蔽"（Shadowing）：

```rust
fn main() {
    let x = 5;
    println!("第一次声明的 x：{}", x);
    
    let x = x + 1;  // 遮蔽前面的 x
    println!("遮蔽后的 x：{}", x);
    
    let x = "字符串";  // 可以改变类型！
    println!("变成字符串的 x：{}", x);
}
```

运行结果：
```
第一次声明的 x：5
遮蔽后的 x：6
变成字符串的 x：字符串
```

> **注意**：变量遮蔽与 `mut` 的区别：
> - `mut` 只是允许修改变量的值，但不能改变类型
> - 变量遮蔽（`let`）可以改变类型，因为实际上是创建了一个新变量

### 常量（Constants）

常量使用 `const` 关键字声明，必须标注类型：

```rust
const PI: f64 = 3.14159;
const MAX_SIZE: u32 = 100_000;

fn main() {
    println!("圆周率约等于：{}", PI);
    println!("最大尺寸：{}", MAX_SIZE);
}
```

**常量与不可变变量的区别**：
| 特性 | `let`（不可变） | `const` |
|------|-----------------|---------|
| 可否用 `mut` | 否（不可变） | 不需要 |
| 可否运行时计算 | 可以 | 只能常量表达式 |
| 可否用于全局 | 否 | 可以 |
| 必须标注类型 | 否 | 是 |

## 🔑 关键概念理解

### 为什么要默认不可变？

1. **安全性**：防止意外修改，减少 bug
2. **并发友好**：不可变数据天然线程安全
3. **易于推理**：值不会突然改变，代码更容易理解
4. **编译器优化**：编译器可以更自由地优化不可变数据

### 什么时候用 `mut`？

当你确定这个变量的值需要变化时，比如：
- 计数器
- 累积求和
- 用户输入的存储
- 循环中的迭代变量

### 什么时候用变量遮蔽？

当你需要：
- 在同一个作用域内转换值的类型
- 在复杂的计算过程中暂存中间值
- 创建"新版本"的变量而不是修改原变量

## ✏️ 练习题

### 练习 1：基本变量操作

编写一个程序，声明一个整数变量 `age`，表示年龄，然后打印出来。

```rust
// 提示：尝试声明和打印一个整数变量
fn main() {
    let age = 25;
    println!("我的年龄是：{}", age);
}
```

### 练习 2：计算圆面积

使用常量 `PI` 和变量 `radius`，计算并打印圆的面积。

```rust
const PI: f64 = 3.14159;

fn main() {
    let radius = 5.0;
    let area = PI * radius * radius;
    println!("半径为 {} 的圆面积是：{:.2}", radius, area);
}
```

### 练习 3：变量交换

使用变量遮蔽，交换两个变量的值（不使用 `mut`）。

```rust
fn main() {
    let a = 10;
    let b = 20;
    
    let a = b;  // 这里 a 被遮蔽，值变成 20
    let b = a - 10;  // 这里 b 被遮蔽，值变成 10
    
    println!("a = {}, b = {}", a, b);
}
```

### 练习 4：理解错误

```rust
fn main() {
    let x = 5;
    x = 6;  // 错误：x 是不可变的
    println!("x = {}", x);
}
```

### 练习 5：设计练习

编写一个程序，计算购物车总价。包含：
- 商品单价（不可变）
- 商品数量（可变，因为用户可能会修改）
- 总价（根据数量计算）

```rust
fn main() {
    const UNIT_PRICE: f64 = 29.99;
    let mut quantity = 3;
    
    println!("商品单价：${:.2}", UNIT_PRICE);
    println!("购买数量：{}", quantity);
    
    quantity = 5;  // 用户修改了购买数量
    let total = UNIT_PRICE * quantity as f64;
    
    println!("总价：${:.2}", total);
}
```

## 💭 今日感悟

**学习 Rust 的第一天，印象最深刻的是"默认不可变"这个设计理念。**

大多数编程语言默认变量是可变的（比如 Python、JavaScript），而 Rust 反其道而行之。这让我思考：我们在编写代码时，其实大部分变量在创建后并不需要改变，默认不可变能让代码更安全、更好理解。

变量遮蔽也是一个有趣的概念。它不是修改原有变量，而是创建一个新的同名变量，这在处理类型转换时特别有用。

Rust 的设计哲学是"安全第一"，通过编译器强制执行这些规则。虽然一开始可能觉得麻烦，但相信随着学习的深入，会越来越理解这些设计的深意。
