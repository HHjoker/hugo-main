## 🛠️ 学习环境

推荐使用 [Rust Playground](https://play.rust-lang.org/) 在线编写 Rust 代码，无需安装任何环境。

本地安装：
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

## 💡 学习方法

1. **理论 + 实践**：每篇文章都包含可运行的代码示例
2. **循序渐进**：每天一个主题，不要急于求成
3. **多做练习**：每篇文章末尾都有练习题，动手实践很重要
4. **查阅文档**：遇到问题先看 [官方文档](https://doc.rust-lang.org/)
