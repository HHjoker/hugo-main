## 📚 今日学习内容

### 1. Rust 简介

**Rust 是什么？**

> Rust 是一门系统编程语言，专注于安全、并发和性能。

**核心特性**：

```rust
// 1. 所有权系统 - 无需 GC 的内存安全
let s1 = String::from("hello");
let s2 = s1; // 所有权转移，s1 不再有效

// 2. 借用检查 - 编译期防止数据竞争
fn print(s: &String) { // 借用，不获取所有权
    println!("{}", s);
}

// 3. 模式匹配 - 强大的枚举处理
enum Option<T> {
    Some(T),
    None,
}

// 4. 零成本抽象
let numbers: Vec<i32> = vec![1, 2, 3, 4, 5];
let sum: i32 = numbers.iter().sum(); // 迭代器被优化为循环
```

### 4. Rust 基础语法速览

#### 4.1 变量与可变性

```rust
fn main() {
    // 默认不可变
    let x = 5;
    // x = 6; // 错误！

    // 可变变量
    let mut y = 5;
    y = 6; // 正确

    // 常量
    const MAX_POINTS: u32 = 100_000;

    // 阴影（shadowing）
    let x = 5;
    let x = x + 1; // 新变量，遮蔽旧变量
    let x = x * 2;
    println!("{}", x); // 输出 12
}
```

#### 4.2 数据类型

```rust
fn main() {
    // 整数类型
    let a: i32 = -42;      // 有符号 32 位
    let b: u32 = 42;       // 无符号 32 位
    let c: i64 = 1000;     // 有符号 64 位

    // 浮点类型
    let d: f64 = 3.14;     // 默认 f64
    let e: f32 = 3.14f32;  // 显式 f32

    // 布尔类型
    let f: bool = true;

    // 字符类型
    let g: char = 'A';     // Unicode 标量值

    // 字符串
    let h: &str = "hello"; // 字符串切片
    let i: String = String::from("world"); //  owned String

    // 数组
    let j: [i32; 5] = [1, 2, 3, 4, 5];
    let k = [0; 5]; // [0, 0, 0, 0, 0]

    // 元组
    let l: (i32, f64, char) = (500, 6.4, 'A');
    let (x, y, z) = l; // 解构
}
```

#### 4.3 函数

```rust
fn main() {
    let result = add(5, 3);
    println!("5 + 3 = {}", result);

    let message = greet("Alice");
    println!("{}", message);
}

// 无返回值
fn add(a: i32, b: i32) -> i32 {
    a + b  // 没有分号，表示返回值
}

// 有返回值
fn greet(name: &str) -> String {
    format!("Hello, {}!", name)
}
```

#### 4.4 控制流

```rust
fn main() {
    // if 表达式
    let number = 7;
    let result = if number > 5 { "big" } else { "small" };

    // 循环
    let mut count = 0;
    loop {
        count += 1;
        if count == 3 {
            break;
        }
    }

    // for 循环
    for i in 0..5 {
        println!("{}", i); // 0, 1, 2, 3, 4
    }

    for (index, value) in [1, 2, 3].iter().enumerate() {
        println!("{}: {}", index, value);
    }
}
```

## 💡 关键概念理解

### 所有权（Ownership）- Rust 的核心

```
Rust 通过所有权系统管理内存，无需垃圾回收。

三条规则：
1. 每个值都有一个所有者
2. 值在任一时刻只能有一个所有者
3. 当所有者离开作用域，值被丢弃（内存释放）
```

**示例**：

```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1;  // 所有权转移，s1 不再有效

    // println!("{}", s1); // 错误！s1 已无效

    let s3 = s2.clone();  // 深拷贝，s2 和 s3 都有独立所有权
    println!("{}", s2);   // 正确
    println!("{}", s3);   // 正确
}
```

### 借用（Borrowing）- 引用而不获取所有权

```rust
fn main() {
    let s1 = String::from("hello");
    let len = calculate_length(&s1);  // 借用，不转移所有权
    println!("The length of '{}' is {}.", s1, len);  // s1 仍可用
}

fn calculate_length(s: &String) -> usize {
    s.len()
}  // s 离开作用域，但不释放内存（因为不拥有）
```
