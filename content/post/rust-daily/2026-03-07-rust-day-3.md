## 📚 今日学习内容

### 1. 函数（Functions）

#### 1.1 函数定义

```rust
fn main() {
    let result = add(5, 3);
    println!("5 + 3 = {}", result);
    
    greet("Alice", 25);
}

// 带参数和返回值的函数
fn add(a: i32, b: i32) -> i32 {
    a + b  // 没有分号，表示返回值
}

// 无返回值的函数（返回单元类型 ()）
fn greet(name: &str, age: u8) {
    println!("Hello, {}! You are {} years old.", name, age);
}
```

**关键点**：
- 参数必须标注类型
- 返回值用 `->` 指定
- 最后一个表达式无分号 = 返回值

#### 1.2 表达式 vs 语句

```rust
fn main() {
    // 语句（Statement）：执行操作，不返回值
    let x = 5;  // let 绑定是语句
    
    // 表达式（Expression）：计算并返回值
    let y = {   // 块是表达式
        let a = 3;
        let b = 4;
        a + b   // 没有分号，返回 7
    };
    
    println!("x = {}, y = {}", x, y);
    
    // if 也是表达式
    let num = 10;
    let description = if num > 5 { "big" } else { "small" };
    println!("{}", description);
}
```

**区别**：

| 语句 | 表达式 |
|------|--------|
| 不返回值 | 返回值 |
| 以分号结束 | 不以分号结束 |
| `let x = 5;` | `5` |
| `if cond { }` (有分号) | `if cond { a } else { b }` |

#### 1.3 函数参数

```rust
fn main() {
    // 值传递（Copy 类型）
    let x = 5;
    print_value(x);
    println!("x = {}", x);  // x 仍可用
    
    // 引用传递（非 Copy 类型）
    let s = String::from("hello");
    print_string(&s);
    println!("s = {}", s);  // s 仍可用
}

fn print_value(n: i32) {
    println!("Value: {}", n);
}

fn print_string(s: &String) {
    println!("String: {}", s);
}
```

#### 1.4 多个返回值

使用元组返回多个值：

```rust
fn calculate(x: i32, y: i32) -> (i32, i32, i32) {
    let sum = x + y;
    let diff = x - y;
    let product = x * y;
    (sum, diff, product)
}

fn main() {
    let (s, d, p) = calculate(10, 3);
    println!("Sum: {}, Diff: {}, Product: {}", s, d, p);
    
    // 或者只取部分值
    let (sum, _, _) = calculate(10, 3);
    println!("Only sum: {}", sum);
}
```

### 2. if/else 表达式

#### 2.1 基本用法

```rust
fn main() {
    let number = 7;
    
    // 条件必须是 bool 类型
    if number > 5 {
        println!("number is greater than 5");
    } else {
        println!("number is 5 or less");
    }
    
    // 多个条件
    if number < 3 {
        println!("small");
    } else if number < 7 {
        println!("medium");
    } else {
        println!("large");
    }
}
```

#### 2.2 if 作为表达式

```rust
fn main() {
    let number = 10;
    
    // if 可以返回值，但分支类型必须一致
    let result = if number > 5 {
        100
    } else {
        50
    };
    
    println!("Result: {}", result);
    
    // 错误示例：分支类型不一致
    // let wrong = if number > 5 {
    //     "big"  // &str
    // } else {
    //     42     // i32 - 类型不匹配！
    // };
}
```

### 3. 循环（Loops）

#### 3.1 loop - 无限循环

```rust
fn main() {
    let mut counter = 0;
    
    // 无限循环，需要手动 break
    let result = loop {
        counter += 1;
        
        if counter == 10 {
            break counter * 2;  // break 可以返回值
        }
    };
    
    println!("Counter reached {}, result = {}", counter, result);
}
```

**循环标签（Loop Labels）**：

```rust
fn main() {
    let mut count = 0;
    
    'counting_up: loop {
        println!("count = {}", count);
        
        let mut remaining = 10;
        
        loop {
            println!("remaining = {}", remaining);
            
            if remaining == 9 {
                break;  // 只跳出内层循环
            }
            
            if count == 2 {
                break 'counting_up;  // 跳出外层循环
            }
            
            remaining -= 1;
        }
        
        count += 1;
    }
    
    println!("End count = {}", count);
}
```

#### 3.2 while - 条件循环

```rust
fn main() {
    let mut number = 3;
    
    while number > 0 {
        println!("{}!", number);
        number -= 1;
    }
    
    println!("LIFTOFF!");
}
```

#### 3.3 for - 迭代循环（最常用）

```rust
fn main() {
    // 遍历数组
    let arr = [10, 20, 30, 40, 50];
    
    for element in arr {
        println!("Value: {}", element);
    }
    
    // 使用 enumerate 获取索引
    for (index, value) in arr.iter().enumerate() {
        println!("arr[{}] = {}", index, value);
    }
    
    // 范围迭代
    for i in 1..4 {
        println!("i = {}", i);  // 1, 2, 3（不包含 4）
    }
    
    // 包含上限的范围
    for i in 1..=4 {
        println!("i = {}", i);  // 1, 2, 3, 4
    }
    
    // 倒计时
    for i in (1..=5).rev() {
        println!("{}!", i);
    }
}
```

**for vs while**：

```rust
fn main() {
    let arr = [10, 20, 30, 40, 50];
    
    // while 方式（容易出错）
    let mut index = 0;
    while index < arr.len() {
        println!("while: {}", arr[index]);
        index += 1;
    }
    
    // for 方式（更安全、简洁）
    for element in &arr {
        println!("for: {}", element);
    }
    
    // for 自动处理边界，不会越界
}
```

### 4. match 模式匹配

#### 4.1 基本用法

```rust
fn main() {
    let number = 5;
    
    match number {
        1 => println!("One!"),
        2 => println!("Two!"),
        3 => println!("Three!"),
        _ => println!("Something else"),  // 通配符，匹配其他所有
    }
}
```

**match 是表达式**，可以返回值：

```rust
fn main() {
    let number = 5;
    
    let description = match number {
        1 => "one",
        2 => "two",
        3 => "three",
        _ => "other",
    };
    
    println!("Number is {}", description);
}
```

#### 4.2 匹配多个模式

```rust
fn main() {
    let number = 5;
    
    match number {
        1 | 2 => println!("One or two"),
        3..=5 => println!("Three to five"),  // 范围匹配
        6 | 7 | 8 => println!("Six to eight"),
        _ => println!("Other"),
    }
}
```

#### 4.3 匹配 Option

```rust
fn main() {
    let some_value: Option<i32> = Some(5);
    let none_value: Option<i32> = None;
    
    match some_value {
        Some(x) => println!("Got value: {}", x),
        None => println!("Got nothing"),
    }
    
    match none_value {
        Some(x) => println!("Got value: {}", x),
        None => println!("Got nothing"),
    }
}
```

#### 4.4 if let - 简化的 match

当只关心一个分支时，用 `if let`：

```rust
fn main() {
    let some_value: Option<i32> = Some(5);
    
    // match 写法
    match some_value {
        Some(x) => println!("Got: {}", x),
        _ => (),  // 其他情况什么都不做
    }
    
    // if let 写法（更简洁）
    if let Some(x) = some_value {
        println!("Got: {}", x);
    }
    
    // if let else
    let value: Option<i32> = None;
    if let Some(x) = value {
        println!("Got: {}", x);
    } else {
        println!("Got nothing");
    }
}
```

#### 4.5 while let - 循环匹配

```rust
fn main() {
    let mut stack = vec![1, 2, 3];
    
    while let Some(top) = stack.pop() {
        println!("Popped: {}", top);
    }
    // 输出：3, 2, 1
}
```

## 💡 关键概念理解

### 1. 表达式返回值

```rust
fn main() {
    // 块表达式的值是最后一个表达式的值
    let x = {
        let a = 5;
        let b = 10;
        a + b  // 返回值 15，没有分号
    };
    
    // 如果加分号，返回 ()
    let y = {
        let a = 5;
        a + 1;  // 有分号，是语句
    };  // y = ()
    
    println!("x = {}", x);
    // println!("y = {}", y);  // 错误！y 是 ()
}
```

### 2. match 必须穷尽

```rust
fn main() {
    let number = 5;
    
    // 错误：没有覆盖所有情况
    // match number {
    //     1 => println!("One"),
    //     2 => println!("Two"),
    // }  // 编译错误：non-exhaustive patterns
    
    // 正确：使用 _ 通配符
    match number {
        1 => println!("One"),
        2 => println!("Two"),
        _ => println!("Other"),
    }
}
```

### 3. for 循环的迭代器

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5];
    
    // 借用迭代（最常用）
    for x in &arr {
        println!("{}", x);  // x 是 &i32
    }
    
    // 可变借用迭代
    let mut arr2 = [1, 2, 3];
    for x in &mut arr2 {
        *x += 1;  // x 是 &mut i32，需要解引用
    }
    println!("{:?}", arr2);  // [2, 3, 4]
    
    // 所有权迭代（消耗数组）
    for x in arr {
        println!("{}", x);  // x 是 i32
    }
    // arr 之后不能再使用
}
```

## 💭 今日感悟

> 函数是 Rust 的基石之一。记住：**最后一个表达式无分号就是返回值**，这个规则一开始容易忘记。

> if/else 在 Rust 中是表达式而不是语句，这个设计很优雅。可以直接赋值，代码更简洁。

> for 循环比 while 更安全，因为它自动处理边界，不会越界。以后应该优先使用 for。

> match 是 Rust 最强大的特性之一。它强制你处理所有情况，避免了遗漏分支的 bug。配合枚举使用效果更佳。

> if let 和 while let 是 match 的语法糖，在只关心一个分支时很方便。
