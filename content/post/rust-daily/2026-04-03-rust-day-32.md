## 📚 学习内容

### 什么是 HashMap？

`HashMap` 是 Rust 中的**哈希表**实现，它存储**键值对**（key-value pairs）。与 Vec 通过索引访问不同，HashMap 通过键（key）来访问值（value）。

```rust
use std::collections::HashMap;

fn main() {
    // 创建一个 HashMap，存储姓名和年龄
    let mut scores = HashMap::new();
    
    scores.insert("Alice", 25);
    scores.insert("Bob", 30);
    scores.insert("Charlie", 35);
    
    // 通过键访问值
    let age = scores.get("Alice");
    println!("Alice 的年龄：{:?}", age); // Some(25)
}
```

### 访问 HashMap 中的值

```rust
use std::collections::HashMap;

fn main() {
    let mut scores = HashMap::new();
    scores.insert("Alice", 90);
    scores.insert("Bob", 85);
    scores.insert("Charlie", 95);
    
    // 方法 1: 使用 get()（推荐，安全）
    match scores.get("Alice") {
        Some(score) => println!("Alice 的分数：{}", score),
        None => println!("未找到 Alice"),
    }
    
    // 方法 2: 使用 entry API（用于插入或更新）
    let alice_score = scores.entry("Alice").or_insert(0);
    println!("Alice 的分数：{}", alice_score);
    
    // 方法 3: 直接索引（不推荐，会 panic）
    // let score = scores["Alice"]; // 如果键不存在会 panic！
    
    // 检查键是否存在
    if scores.contains_key("Bob") {
        println!("Bob 在 HashMap 中");
    }
}
```

### 修改 HashMap

```rust
use std::collections::HashMap;

fn main() {
    let mut scores = HashMap::new();
    
    // 插入新值
    scores.insert("Alice", 90);
    println!("插入后：{:?}", scores);
    
    // 更新已有值
    scores.insert("Alice", 95);
    println!("更新后：{:?}", scores);
    
    // 使用 entry API 进行条件更新
    let score = scores.entry("Bob").or_insert(80);
    *score += 5; // 如果 Bob 不存在，插入 80；如果存在，加 5
    
    println!("entry 操作后：{:?}", scores);
    
    // 删除键值对
    let removed = scores.remove("Alice");
    println!("删除的 값: {:?}", removed); // Some(95)
    println!("删除后：{:?}", scores);
    
    // 清空所有
    scores.clear();
    println!("清空后：{:?}", scores); // {}
}
```

### Entry API 详解

Entry API 是 HashMap 最强大的功能之一，它可以避免多次查找。

```rust
use std::collections::HashMap;

fn main() {
    let mut word_count = HashMap::new();
    let words = vec!["apple", "banana", "apple", "orange", "banana", "apple"];
    
    // 传统方式（需要两次查找）
    for word in &words {
        if word_count.contains_key(word) {
            let count = word_count.get_mut(word).unwrap();
            *count += 1;
        } else {
            word_count.insert(word, 1);
        }
    }
    
    // 使用 entry API（只需一次查找）
    word_count.clear();
    for word in &words {
        *word_count.entry(word).or_insert(0) += 1;
    }
    
    println!("{:?}", word_count);
    // {"apple": 3, "banana": 2, "orange": 1}
    
    // entry 的各种方法
    let mut map: HashMap<&str, i32> = HashMap::new();
    
    // or_insert: 如果键不存在则插入默认值
    let value = map.entry("key1").or_insert(100);
    
    // or_insert_with: 使用闭包提供默认值
    let value = map.entry("key2").or_insert_with(|| {
        println!("计算默认值...");
        200
    });
    
    // and_modify: 如果键存在则修改
    map.entry("key1").and_modify(|v| *v += 50);
    
    // or_default: 插入类型的默认值
    map.entry("key3").or_default();
    
    println!("{:?}", map);
}
```

### 遍历 HashMap

```rust
use std::collections::HashMap;

fn main() {
    let mut scores = HashMap::new();
    scores.insert("Alice", 90);
    scores.insert("Bob", 85);
    scores.insert("Charlie", 95);
    
    // 遍历所有键值对（不可变借用）
    println!("遍历键值对:");
    for (key, value) in &scores {
        println!("{}: {}", key, value);
    }
    
    // 遍历所有键值对（可变借用）
    println!("\n修改后:");
    for (key, value) in &mut scores {
        *value += 5;
        println!("{}: {}", key, value);
    }
    
    // 只遍历键
    println!("\n只遍历键:");
    for key in scores.keys() {
        println!("键：{}", key);
    }
    
    // 只遍历值
    println!("\n只遍历值:");
    for value in scores.values() {
        println!("值：{}", value);
    }
    
    // 消耗性遍历（转移所有权）
    println!("\n消耗性遍历:");
    for (key, value) in scores {
        println!("{}: {}", key, value);
    }
    // scores 不能再使用了
}
```

### HashMap 与 Vec 的结合

```rust
use std::collections::HashMap;

fn main() {
    // HashMap 的值可以是 Vec
    let mut student_scores: HashMap<&str, Vec<i32>> = HashMap::new();
    
    student_scores.insert("Alice", vec![90, 85, 88]);
    student_scores.insert("Bob", vec![75, 80, 82]);
    
    // 添加新分数
    student_scores.entry("Alice").or_insert_with(Vec::new).push(92);
    
    // 计算每个学生的平均分
    for (name, scores) in &student_scores {
        let avg: f64 = scores.iter().sum::<i32>() as f64 / scores.len() as f64;
        println!("{} 的平均分：{:.2}", name, avg);
    }
    
    // Vec 的元素可以是 HashMap
    let mut students: Vec<HashMap<&str, String>> = Vec::new();
    
    let mut alice = HashMap::new();
    alice.insert("name", "Alice".to_string());
    alice.insert("major", "CS".to_string());
    students.push(alice);
    
    let mut bob = HashMap::new();
    bob.insert("name", "Bob".to_string());
    bob.insert("major", "Math".to_string());
    students.push(bob);
    
    for student in &students {
        println!("{:?}", student);
    }
}
```

### 自定义类型作为 HashMap 的键

```rust
use std::collections::HashMap;
use std::hash::{Hash, Hasher};

#[derive(Debug, Eq, PartialEq, Hash)]
struct Point {
    x: i32,
    y: i32,
}

fn main() {
    let mut map = HashMap::new();
    
    let p1 = Point { x: 1, y: 2 };
    let p2 = Point { x: 3, y: 4 };
    
    map.insert(p1, "第一象限");
    map.insert(p2, "第一象限");
    
    // 查找
    let query = Point { x: 1, y: 2 };
    match map.get(&query) {
        Some(location) => println!("找到：{}", location),
        None => println!("未找到"),
    }
    
    // 注意：自定义类型必须实现 Hash 和 PartialEq trait
}

// 对于简单场景，可以使用派生宏
#[derive(Debug, Eq, PartialEq, Hash)]
struct Color {
    r: u8,
    g: u8,
    b: u8,
}
```

### HashMap 的性能特点

```rust
use std::collections::HashMap;
use std::time::Instant;

fn main() {
    let mut map = HashMap::new();
    
    // 插入性能
    let start = Instant::now();
    for i in 0..10000 {
        map.insert(i, i * 2);
    }
    println!("插入 10000 个元素耗时：{:?}", start.elapsed());
    
    // 查找性能（O(1) 平均时间复杂度）
    let start = Instant::now();
    for i in 0..10000 {
        let _ = map.get(&i);
    }
    println!("查找 10000 次耗时：{:?}", start.elapsed());
    
    // HashMap 的平均时间复杂度：
    // - 插入：O(1)
    // - 查找：O(1)
    // - 删除：O(1)
    // 最坏情况（哈希冲突严重时）：O(n)
}
```

## 🔑 关键概念理解

### 1. HashMap 的工作原理

HashMap 使用**哈希函数**将键转换为索引，然后在内部数组的对应位置存储值。

```
键 "Alice" → 哈希函数 → 索引 5 → 存储值 90
键 "Bob"   → 哈希函数 → 索引 2 → 存储值 85
```

### 2. 为什么需要 Hash 和 Eq trait？

- **Hash**：用于计算键的哈希值
- **Eq**：用于在哈希冲突时比较键是否相等

```rust
// 可以作为 HashMap 键的类型必须满足：
// 1. 实现 Hash trait
// 2. 实现 Eq trait（和 PartialEq）

// 这些类型可以直接使用：
// - 整数类型（i32, u64 等）
// - 布尔类型（bool）
// - 字符串（String, &str）
// - 元组（如果所有元素都满足条件）

// 这些类型不能直接使用：
// - f32, f64（不实现 Hash，因为浮点数相等比较复杂）
// - 自定义结构体（需要派生或手动实现）
```

### 3. Entry API 的优势

```rust
// 传统方式：需要多次查找
if map.contains_key(&key) {
    let value = map.get_mut(&key).unwrap();
    *value += 1;
} else {
    map.insert(key, 1);
}

// Entry API：只需一次查找
*map.entry(key).or_insert(0) += 1;
```

### 4. HashMap 不保证顺序

```rust
let mut map = HashMap::new();
map.insert("a", 1);
map.insert("b", 2);
map.insert("c", 3);

// 遍历顺序是不确定的！
for (k, v) in &map {
    println!("{}: {}", k, v);
}

// 如果需要保持插入顺序，使用 IndexMap crate
// 如果需要按键排序，使用 BTreeMap
```

### 5. HashMap vs BTreeMap

| 特性 | HashMap | BTreeMap |
|------|---------|----------|
| 查找速度 | O(1) 平均 | O(log n) |
| 顺序 | 无序 | 按键排序 |
| 内存 | 较少 | 较多 |
| 使用场景 | 大多数情况 | 需要有序遍历时 |

use std::collections::HashMap;

fn word_count(text: &str) -> HashMap<String, usize> {
    let mut counts = HashMap::new();
    
    for word in text.split_whitespace() {
        let word = word.to_lowercase();
        let word = word.trim_matches(|c: char| !c.is_alphanumeric());
        
        *counts.entry(word).or_insert(0) += 1;
    }
    
    counts
}

fn main() {
    let text = "hello world hello rust world hello";

### 练习 2：两数之和（HashMap 优化版）

使用 HashMap 优化 Day 31 的两数之和题目，将时间复杂度从 O(n²) 降到 O(n)。

<details>
<summary>点击查看答案</summary>

```rust
use std::collections::HashMap;

fn two_sum(nums: Vec<i32>, target: i32) -> Option<(usize, usize)> {
    let mut map = HashMap::new();
    
    for (i, &num) in nums.iter().enumerate() {
        let complement = target - num;
        
        if let Some(&j) = map.get(&complement) {
            return Some((j, i));
        }
        
        map.insert(num, i);
    }
    
    None
}

fn main() {
    let nums = vec![2, 7, 11, 15];
    let target = 9;
    
    match two_sum(nums, target) {
        Some((i, j)) => println!("找到：索引 {} 和 {}", i, j),
        None => println!("未找到"),
    }
}
```

### 练习 3：电话簿

实现一个简单的电话簿，支持添加、查找、删除联系人。

<details>
<summary>点击查看答案</summary>

```rust
use std::collections::HashMap;

struct PhoneBook {
    contacts: HashMap<String, String>,
}

impl PhoneBook {
    fn new() -> Self {
        PhoneBook {
            contacts: HashMap::new(),
        }
    }
    
    fn add(&mut self, name: &str, phone: &str) {
        self.contacts.insert(name.to_string(), phone.to_string());
        println!("已添加：{} -> {}", name, phone);
    }
    
    fn find(&self, name: &str) -> Option<&String> {
        self.contacts.get(name)
    }
    
    fn remove(&mut self, name: &str) -> Option<String> {
        match self.contacts.remove(name) {
            Some(phone) => {
                println!("已删除：{} 的电话号码 {}", name, phone);
                Some(phone)
            }
            None => {
                println!("未找到：{}", name);
                None
            }
        }
    }
    
    fn list(&self) {
        println!("\n=== 电话簿 ===");
        for (name, phone) in &self.contacts {
            println!("{}: {}", name, phone);
        }
        println!("==============\n");
    }
}

fn main() {
    let mut book = PhoneBook::new();
    
    book.add("Alice", "123-4567");
    book.add("Bob", "234-5678");
    book.add("Charlie", "345-6789");
    
    book.list();
    
    if let Some(phone) = book.find("Alice") {
        println!("Alice 的电话：{}", phone);
    }
    
    book.remove("Bob");
    book.list();
}
```

use std::collections::HashMap;

fn group_and_sum(numbers: Vec<i32>) -> HashMap<&'static str, i32> {
    let mut groups = HashMap::new();
    
    for num in numbers {
        let key = if num % 2 == 0 { "even" } else { "odd" };
        *groups.entry(key).or_insert(0) += num;
    }
    
    groups
}

fn main() {

### 练习 5：缓存系统

实现一个简单的 LRU（最近最少使用）缓存。

<details>
<summary>点击查看答案</summary>

```rust
use std::collections::HashMap;

struct LRUCache {
    capacity: usize,
    data: HashMap<String, String>,
    order: Vec<String>,
}

impl LRUCache {
    fn new(capacity: usize) -> Self {
        LRUCache {
            capacity,
            data: HashMap::new(),
            order: Vec::new(),
        }
    }
    
    fn get(&mut self, key: &str) -> Option<String> {
        match self.data.get(key) {
            Some(value) => {
                // 更新访问顺序
                if let Some(pos) = self.order.iter().position(|k| k == key) {
                    self.order.remove(pos);
                }
                self.order.push(key.to_string());
                Some(value.clone())
            }
            None => None,
        }
    }
    
    fn put(&mut self, key: String, value: String) {
        // 如果已存在，先删除旧记录
        if self.data.contains_key(&key) {
            if let Some(pos) = self.order.iter().position(|k| k == &key) {
                self.order.remove(pos);
            }
        }
        
        // 如果超出容量，删除最旧的
        while self.data.len() >= self.capacity && !self.order.is_empty() {
            let oldest = self.order.remove(0);
            self.data.remove(&oldest);
        }
        
        self.data.insert(key.clone(), value);
        self.order.push(key);
    }
}

fn main() {
    let mut cache = LRUCache::new(2);
    
    cache.put("a".to_string(), "1".to_string());
    cache.put("b".to_string(), "2".to_string());
    
    println!("{:?}", cache.get("a")); // Some("1")
    
    cache.put("c".to_string(), "3".to_string()); // 超出容量，删除 "b"
    
    println!("{:?}", cache.get("b")); // None
    println!("{:?}", cache.get("c")); // Some("3")
}
```

## 💭 今日感悟

今天学习了 HashMap，它是 Rust 中最灵活的集合类型之一。有几个关键点让我印象深刻：

1. **Entry API 的优雅**：这是 Rust 设计中最巧妙的 API 之一。它避免了多次查找，代码也更简洁。一旦习惯了 `entry().or_insert()` 的模式，就回不去了。

2. **哈希表的威力**：O(1) 的查找速度在实际应用中非常重要。今天练习中的两数之和优化，从 O(n²) 到 O(n)，这就是算法的力量。

3. **类型系统的约束**：HashMap 要求键实现 Hash 和 Eq trait，这看起来是限制，但实际上是保护。它确保了 HashMap 的正确性和安全性。

4. **所有权与集合**：HashMap 完全遵循 Rust 的所有权规则。理解何时借用、何时转移所有权，是使用 HashMap 的关键。

5. **无序的特性**：HashMap 不保证顺序，这在某些场景下是问题。需要记住 BTreeMap 这个替代方案，它在需要有序时很有用。
