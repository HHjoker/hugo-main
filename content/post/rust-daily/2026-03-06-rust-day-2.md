## 📚 今日学习内容

### 1. 变量绑定与可变性

#### 1.1 默认不可变

Rust 的变量默认是**不可变**的，这是安全性的第一道防线。

```rust
fn main() {
    let x = 5;
    println!("x = {}", x);
    
    // x = 6;  // 错误！无法给不可变变量重新赋值
    // 编译错误：cannot assign twice to immutable variable `x`
}
```

**为什么默认不可变？**
- 防止意外修改
- 便于编译器优化
- 减少并发编程中的数据竞争

#### 1.2 可变变量

使用 `mut` 关键字声明可变变量。

```rust
fn main() {
    let mut counter = 0;
    println!("counter = {}", counter);
    
    counter = 1;
    println!("counter = {}", counter);
    
    counter += 1;
    println!("counter = {}", counter);
}
```

#### 1.3 阴影（Shadowing）

阴影允许你用同一个变量名创建新变量，**不同于可变性**。

```rust
fn main() {
    let x = 5;
    let x = x + 1;      // 新变量 x，遮蔽了旧 x
    let x = x * 2;
    println!("x = {}", x);  // 输出 12
    
    // 阴影可以改变类型
    let spaces = "   ";
    let spaces = spaces.len();  // &str → usize
    println!("spaces = {}", spaces);
    
    // 如果用 mut 就无法改变类型
    let mut spaces_mut = "   ";
    // spaces_mut = spaces_mut.len();  // 错误！类型不匹配
}
```

**阴影 vs 可变性**：

| 特性 | 阴影 | 可变性 (mut) |
|------|------|-------------|
| 改变类型 | ✅ 可以 | ❌ 不可以 |
| 重新绑定 | ✅ 创建新变量 | ❌ 修改原变量 |
| 适用场景 | 类型转换、转换后不再需要原值 | 需要多次修改同一值 |

### 2. 标量类型（Scalar Types）

#### 2.1 整数类型

| 长度 | 有符号 | 无符号 |
|------|--------|--------|
| 8-bit | `i8` | `u8` |
| 16-bit | `i16` | `u16` |
| 32-bit | `i32` | `u32` |
| 64-bit | `i64` | `u64` |
| 128-bit | `i128` | `u128` |
| 架构相关 | `isize` | `usize` |

```rust
fn main() {
    // 默认类型：i32
    let default_int = 42;  // i32
    
    // 显式类型
    let explicit_i32: i32 = 42;
    let explicit_u8: u8 = 255;
    
    // 数字字面量格式
    let decimal = 99_220;      // 十进制
    let hex = 0xff;            // 十六进制
    let octal = 0o77;          // 八进制
    let binary = 0b1111_0000;  // 二进制
    let byte = b'A';           // 字节 (u8)
    
    println!("decimal: {}", decimal);
    println!("hex: {}", hex);
    println!("octal: {}", octal);
    println!("binary: {}", binary);
    println!("byte: {}", byte);
}
```

**整数溢出**：

```rust
fn main() {
    // debug 模式：溢出会 panic
    let x: u8 = 255;
    // let y = x + 1;  // panic: attempt to add with overflow
    
    // release 模式：溢出会回绕
    // 可以使用 checked 方法安全处理
    let result = x.checked_add(1);  // Option<u8>
    match result {
        Some(val) => println!("Result: {}", val),
        None => println!("Overflow!"),
    }
}
```

#### 2.2 浮点类型

```rust
fn main() {
    // 默认类型：f64（更快，现代 CPU 原生支持）
    let default_float = 3.14;  // f64
    
    // 显式类型
    let f64_val: f64 = 3.14159265359;
    let f32_val: f32 = 3.14f32;
    
    // 科学计数法
    let large = 1.0e6;   // 1000000.0
    let small = 2.5e-3;  // 0.0025
    
    println!("f64: {}", f64_val);
    println!("f32: {}", f32_val);
    println!("large: {}", large);
    println!("small: {}", small);
}
```

#### 2.3 布尔类型

```rust
fn main() {
    let is_true: bool = true;
    let is_false: bool = false;
    
    // 布尔运算
    let and_result = is_true && is_false;
    let or_result = is_true || is_false;
    let not_result = !is_true;
    
    println!("AND: {}", and_result);
    println!("OR: {}", or_result);
    println!("NOT: {}", not_result);
}
```

#### 2.4 字符类型

Rust 的 `char` 是 **Unicode 标量值**（4 字节），不是 ASCII。

```rust
fn main() {
    let letter = 'A';           // ASCII
    let emoji = '🦀';           // Emoji
    let chinese = '中';          // 中文
    let heart = '❤';            // 符号
    
    println!("letter: {}", letter);
    println!("emoji: {}", emoji);
    println!("chinese: {}", chinese);
    println!("heart: {}", heart);
    
    // char 是 4 字节
    println!("size of char: {} bytes", std::mem::size_of::<char>());
}
```

### 3. 复合类型（Compound Types）

#### 3.1 元组（Tuple）

固定长度的有序集合，**可以包含不同类型**。

```rust
fn main() {
    // 创建元组
    let tuple: (i32, f64, char) = (500, 6.4, 'A');
    
    // 访问元素
    let x = tuple.0;
    let y = tuple.1;
    let z = tuple.2;
    println!("({}, {}, {})", x, y, z);
    
    // 解构
    let (a, b, c) = tuple;
    println!("({}, {}, {})", a, b, c);
    
    // 部分解构
    let (first, ..) = (1, 2, 3, 4, 5);
    println!("first = {}", first);
    
    // 空元组（单元类型）
    let unit: () = ();
    println!("unit type: {:?}", unit);
}
```

**元组作为函数返回值**：

```rust
fn get_coordinates() -> (i32, i32, i32) {
    (10, 20, 30)
}

fn main() {
    let (x, y, z) = get_coordinates();
    println!("Position: ({}, {}, {})", x, y, z);
}
```

#### 3.2 数组（Array）

固定长度的有序集合，**必须是相同类型**。

```rust
fn main() {
    // 创建数组
    let arr1: [i32; 5] = [1, 2, 3, 4, 5];
    let arr2 = [0; 5];  // [0, 0, 0, 0, 0]
    
    // 访问元素
    let first = arr1[0];
    let third = arr1[2];
    println!("first: {}, third: {}", first, third);
    
    // 数组长度
    println!("length: {}", arr1.len());
    
    // 遍历数组
    for (index, value) in arr1.iter().enumerate() {
        println!("arr[{}] = {}", index, value);
    }
}
```

**数组边界检查**：

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5];
    
    // Rust 会在运行时检查边界
    // 访问越界会 panic，而不是返回垃圾数据
    let index = 10;
    // let value = arr[index];  // panic: index out of bounds
    
    // 安全访问
    match arr.get(index) {
        Some(val) => println!("Value: {}", val),
        None => println!("Index {} is out of bounds", index),
    }
}
```

#### 3.3 切片（Slice）

切片是**对数组一部分的引用**，不拥有数据。

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5];
    
    // 创建切片
    let slice: &[i32] = &arr[1..3];  // [2, 3]
    
    println!("slice: {:?}", slice);
    println!("slice length: {}", slice.len());
    
    // 切片语法
    let full = &arr[..];      // 整个数组
    let start = &arr[0..2];   // [1, 2]
    let end = &arr[2..];      // [3, 4, 5]
    let last = &arr[3..5];    // [4, 5]
    
    println!("full: {:?}", full);
    println!("start: {:?}", start);
    println!("end: {:?}", end);
    println!("last: {:?}", last);
}
```

**切片作为函数参数**：

```rust
fn print_slice(slice: &[i32]) {
    println!("Slice: {:?}", slice);
}

fn sum_slice(slice: &[i32]) -> i32 {
    slice.iter().sum()
}

fn main() {
    let arr = [1, 2, 3, 4, 5];
    print_slice(&arr[1..4]);
    println!("Sum: {}", sum_slice(&arr));
}
```

### 4. 类型推断

Rust 编译器可以自动推断类型。

```rust
fn main() {
    // 编译器推断为 i32
    let x = 5;
    
    // 编译器推断为 &str
    let greeting = "Hello";
    
    // 编译器推断为 Vec<i32>
    let numbers = vec![1, 2, 3];
    
    // 需要类型注解的情况
    let guess: u32 = "42".parse().expect("Not a number!");
    
    // 使用 turbofish 语法显式指定类型
    let numbers2 = vec![1, 2, 3];
    let sum = numbers2.iter().sum::<i32>();
}
```

## 💡 关键概念理解

### 1. 栈 vs 堆

```
栈（Stack）：
- 后进先出（LIFO）
- 大小固定，编译期已知
- 访问速度快
- 存放：标量类型、数组（固定大小）

堆（Heap）：
- 动态分配
- 大小运行时确定
- 访问速度较慢
- 存放：String、Vec 等动态类型
```

### 2. Copy Trait

某些类型实现 `Copy` trait，赋值时**复制**而不是**移动**。

```rust
fn main() {
    // 实现 Copy 的类型（栈上类型）
    let x = 5;
    let y = x;  // 复制，x 和 y 都有效
    println!("x = {}, y = {}", x, y);
    
    // 不实现 Copy 的类型（堆上类型）
    let s1 = String::from("hello");
    let s2 = s1;  // 移动，s1 无效
    // println!("{}", s1);  // 错误
    println!("{}", s2);  // 正确
}
```

**实现 Copy 的类型**：
- 所有整数类型（`i32`, `u32` 等）
- 布尔类型（`bool`）
- 浮点类型（`f32`, `f64`）
- 字符类型（`char`）
- 元组（如果所有元素都实现 Copy）
